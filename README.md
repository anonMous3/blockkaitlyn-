# BlockKaitlyn

A Tampermonkey userscript for automatically hiding posts from a specific user on Twitter.now.

## 🚀 Installation

### 1. Install Tampermonkey

If you don't already have Tampermonkey installed, get it here:

* [Tampermonkey](https://www.tampermonkey.net/)

### 2. Install BlockKaitlyn

**👉 [Click here to install the userscript](https://raw.githubusercontent.com/anonMous3/blockkaitlyn-/main/Block%20Specific%20User%27s%20Posts%20%28twitter.now%29-1.0.user.js)**

Tampermonkey should automatically open the script installation page.

Click **Install** and the script will be enabled.

## ✨ Features

* Automatically hides posts from the specified user.
* Runs directly in your browser through Tampermonkey.
* No external application or server required.
* Lightweight JavaScript userscript.

## 🔧 Manual Installation

If the automatic installation link doesn't work:

1. Open the **Tampermonkey Dashboard**.
2. Click **Create a new script**.
3. Open the [`Block Specific User's Posts (twitter.now)-1.0.user.js`](https://github.com/anonMous3/blockkaitlyn-/blob/main/Block%20Specific%20User%27s%20Posts%20%28twitter.now%29-1.0.user.js) file on GitHub.
4. Copy the script contents.
5. Paste them into the Tampermonkey editor.
6. Save the script.

## 🔄 Updates

Tampermonkey can automatically check GitHub for newer versions of the userscript when update metadata is configured.
